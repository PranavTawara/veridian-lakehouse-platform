# 0001 — [one-line title of the decision]

This is a filled-out example so the format is obvious — delete it once you've written your first
real one. Name subsequent files `0002-...`, `0003-...` etc., in the order you made the decisions.

**Date:** YYYY-MM-DD

**What:** State the decision in one or two sentences, as something you actually did, not a topic.
("Deduplicated `branch_master` by keeping the row with the most recently-looking `open_date` when
`branch_code` collides, rather than the first or last row in file order" — not "Handling duplicate
branches.")

**Why:** The reasoning that led here. What made the obvious approach wrong, or what made this the
least-bad option given what the data actually showed.

**Alternatives considered:** At least one other option you didn't take, and why not. If there wasn't
a real alternative, say that instead of inventing one.

**Consequences:** What this decision costs you or constrains later — every real decision has a
trade-off. If reviewing this again with more time would change your answer, say so.
